# Mock dataset (AI-written)

**Written by Claude (AI) for development only.** All groups, people, venues and web addresses are fictional; web addresses use the reserved `example.org` domain, and phone numbers are obviously fake.

It exists so the pipeline could be built before the group's own evaluation set (`../group/`) was ready. It covers the same kinds of traps (duplicates, wrong region, place names, street addresses, business names, an unknown café, missing time, past dates, relative dates, personal data, internal events, clashes, weekly activities, nynorsk, informal posts). Submissions 016 and 017 use the public business address or name of real businesses in the region, but the events themselves are fictional, but the pipeline is evaluated against the group's set, not this one.
